# RUN: 20260526-040345495_docs-niid-visual-review-run-plan

## 目的

#178で確認したNIID付表・別表の難表について、通常コードの汎用化ではなく、全体計画後の視覚レビュー復元RUNとして扱う方針を計画へ追記する。

このRUNはドキュメント整備であり、正式な正規化RUNではない。`data/normalized/` への昇格は行わない。

## 背景

`付表2`, `付表4`, `別表7`, `別表10` では、PDFテキストレイヤーだけでは次の構造を安定復元できない。

- セル結合
- 複数行セル
- セル内改行
- 複数行にまたがる折返しセル
- 罫線と見た目でしか分からない列境界

したがって、次のRUNでも一定範囲まではコードで復元し、どうしても視覚処理が必要な箇所はwarning/raw保持に倒す。最後に `NIID付表/別表の視覚レビュー復元RUN` を切り、PDFページ画像を根拠にCodex視覚処理で仕上げる。

## 実施内容

- `docs/REMAINING_NORMALIZATION_PLAN_6_9.md` に視覚レビュー復元RUN方針を追加した。
- NIID難表を通常コードの汎用化対象から分離し、後段の視覚レビュー工程として位置づけた。
- `N` 以降の計画番号を繰り下げた。

## 判断

視覚レビュー復元RUNは、現在のparser/adapter開発を止めるものではない。次の通常開発RUNでは、再現可能なコード処理で進められる範囲をやり切り、復元不能箇所は理由付きwarningとして残す。
