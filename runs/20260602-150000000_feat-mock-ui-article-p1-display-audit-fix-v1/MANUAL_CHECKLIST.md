# 仕様ベース手動チェックリスト: 第一条第一項統合表示

このチェックリストは、コード出力ではなく仕様を基準にする。

目的:

- mock UI のコードが仕様に合っているかを確認する。
- 左側 `チェック項目選択` は、選択操作にだけ使う。
- 判定は右側 `チェックシート` の表示で行う。

## 確定仕様

1. データ上の親子関係は絶対に崩さない。
2. 第一項統合表示は、国内法の第一項だけに対する表示上の例外である。
3. 第一項統合ONでは、第一項は `第一条　<第一項本文>` と表示する。
4. 第一項統合OFFでは、第一項は `第一条` と `１　<第一項本文>` に分けて表示する。
5. 第二項以降は第一項統合の対象外である。
6. 親・先祖文脈は原則表示する。
7. 親item未選択で子・孫だけを選択しても、親item文脈は原則表示する。
8. `兄弟のみ先祖省略` は、同じ親を持つ兄弟を連続表示する場合だけ、共通する先祖文脈を省略する。
9. `兄弟のみ先祖省略` では、親子・従兄弟・別親の文脈は省略しない。
10. `共通先祖省略` は、連続表示時に共通する先祖文脈を省略する。
11. 第一項統合後の表示文字列を、省略判定や親子関係判定に使ってはいけない。
