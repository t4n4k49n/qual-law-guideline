## 目的
- 表示例ショートカットを設定ファイル駆動に統一し、モック専用の裏解決ロジックを排除する。
- 表示例の法令ソース指定を `data/normalized` だけでなく `out/<run_id>` まで拡張する。
- チェック項目選択UIの `nid` 参照・コピー作業を改善する。
- 文脈省略モードのラベルと内部挙動の不一致（スワップ）を仕様どおりに修正する。

## 変更内容
- `data/mock_ui/display_examples.yaml` を正式な表示例設定として運用。
- `selection_resolver_key` を廃止し、`selection_nids` のみで選択を定義する方式に統一。
- 旧デモ注入/旧デモ解決ロジックを無効化・撤去し、法令切替時の選択状態クリアを維持。
- 表示例の `law_folder` で `out/*` バンドルを選択可能に拡張。
- WHO固定分岐を廃止し、表示例設定経由でWHO LBMを読み込む方式に統一。
- 候補行 `🆔` のクリックで `nid` をクリップボードへコピーできるように改善（装飾は透明化）。
- 文脈省略モード割当を修正
  - `共通先祖省略 -> prefix`
  - `兄弟のみ先祖省略 -> exact`

## テスト
- `python -m pytest -q tests/test_mock_ui_render.py`
  - 結果: 14 passed

## まとめ
表示例運用を「コード内の例外分岐」から「管理者が編集可能な設定ファイル」へ統一し、運用変更時の改修コストと属人性を下げた。あわせて法令ソース選択の柔軟性（`out/*` 対応）と、`nid` 参照作業の効率（コピー対応）を改善し、日常の検証・調整サイクルを短縮できる状態にした。さらに文脈省略モードのラベルと実挙動の整合を回復し、仕様理解と実表示のズレを解消した。
